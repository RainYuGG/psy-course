# Spec Delta: course-scraping

## Purpose

定義臨床心理師繼續教育課程之自動抓取、12 欄位規則式抽取、臨床心理師積分白名單比對與跨平台去重之行為規範，確保在不依賴付費 API 的前提下穩定產出結構化課程資料。

## ADDED Requirements

### Requirement: A 類公學會官網課程列表與內頁抓取
系統 SHALL 支援從設定之 A 類台灣心理相關公學會官網抓取近期公布的課程公告與活動內頁，並對單一網站連線異常具備容錯隔離能力。

#### Scenario: 正常抓取多站課程公告并排除非課程訊息
- **WHEN** 執行爬蟲更新任務且目標公學會網站（如臨床心理師公會、臨床心理學會、遊戲治療學會等）正常回應
- **THEN** 系統 MUST 擷取課程或研討會公告連結與內頁內容，並過濾「徵才」、「會務會議紀錄」或「法規公告」等非課程項目

#### Scenario: 單一來源網站維護或連線失敗時不中斷整體任務
- **WHEN** 某個目標網站回傳 HTTP 5xx（如網站維護中）、連線逾時或 SSL 憑證異常
- **THEN** 系統 MUST 記錄該來源的錯誤狀態，對已知憑證鏈不全之站點允許略過驗證，並在其他正常網站繼續完成抓取而不使整體任務失敗

### Requirement: 12 個指定課程欄位純規則抽取與正規化
系統 MUST 從每筆課程公告及內頁中以確定性規則（DOM 結構與正規表示式）抽取並輸出以下 12 個欄位：`課程名稱`、`主辦單位`、`課程日期`、`上課時間`、`費用`、`上課地點／方式`、`報名連結`、`是否有臨床心理師積分`、`積分判斷依據段落`、`資料來源平台`、`建立時間`、`報名期間`。

#### Scenario: 日期正規化為民國年格式
- **WHEN** 課程內文包含西元年日期（如 `2026/07/05` 或 `2026年11月6日`）或民國年日期（如 `115年7月29日`）
- **THEN** 系統 MUST 將 `課程日期` 統一轉換為民國年斜線格式（例如 `115/07/05` 或多日範圍 `115/09/12–115/09/13`），且 `建立時間` MUST 記錄為擷取當日之 `YYYY-MM-DD` 格式

#### Scenario: 費用、時間、地點與報名資訊擷取
- **WHEN** 課程內頁包含標準公文或簡章欄位標記（如 `時間：`、`地點：`、`費用：`、`報名網址：`、`報名期間：`）
- **THEN** 系統 MUST 抽取對應欄位值；若課程內頁未提供外部報名表單網址，則 `報名連結` MUST 回退使用該課程公告內頁網址；若欄位未註明則填寫空字串或預設標記而不拋出例外

### Requirement: 臨床心理師積分三層判斷與原文依據擷取
系統 MUST 區分「臨床心理師積分」與其他醫事人員積分（如諮商心理師積分），並透過台灣臨床心理學會審核通過名單與內文規則將 `是否有臨床心理師積分` 判定為 `是`、`否` 或 `未知`，同時於 `積分判斷依據段落` 保留可稽核之原始文字或認證字號。

#### Scenario: 命中台灣臨床心理學會審核通過白名單
- **WHEN** 課程出現在 `taclip.org.tw/checked-list/` 審核通過課程表，或與該表之「課程名稱＋開始日期」比對相符
- **THEN** `是否有臨床心理師積分` MUST 設為 `是`，且 `積分判斷依據段落` MUST 包含官方認證字號與課程性質（如 `台灣臨床心理學會審核通過（認證字號：TACP...）`）

#### Scenario: 內文明確提及臨床心理師繼續教育積分
- **WHEN** 課程未在白名單直接命中，但內文段落明確包含「臨床心理師」與「繼續教育／積分／學分」（如「臨床心理師、諮商心理師及社工師繼續教育積分申請中」）
- **THEN** `是否有臨床心理師積分` MUST 設為 `是`，且 `積分判斷依據段落` MUST 原文擷取該句段落

#### Scenario: 內文僅泛稱心理師積分或來自純諮商體系且未指明臨床心理師
- **WHEN** 課程內文僅寫「已申請心理師積分」而未指明「臨床心理師」，或完全未提及積分且無法排除有積分
- **THEN** `是否有臨床心理師積分` MUST 設為 `未知`，並於 `積分判斷依據段落` 擷取相關原文或標註「內文未明確提及臨床心理師積分」

#### Scenario: 內文明確標示無申請積分或僅申請非臨床職類積分
- **WHEN** 課程內文明確記載「不申請繼續教育積分」或僅列舉「諮商心理師繼續教育積分」（未含臨床心理師）
- **THEN** `是否有臨床心理師積分` MUST 設為 `否`，並於 `積分判斷依據段落` 擷取該原文句子

### Requirement: 跨來源課程去重與欄位互補合併
系統 SHALL 對不同來源抓取到的同一門課程進行去重，並合併最完整的欄位資訊。

#### Scenario: 學會轉知公告與審核通過名單重複刊登同一課程
- **WHEN** 同一門課程同時出現在台灣臨床心理學會審核通過表（有認證字號但無報名網址与費用）與臨床心理師公會轉知活動訊息（有完整時間、地點、費用與報名連結）
- **THEN** 系統 MUST 依正規化後之課程名稱與課程日期合併為單一筆紀錄，保留完整報名連結、費用、時間與地點，同時保留官方積分認證依據
