# Design

## Context

本專案從零建立「臨床心理師繼續教育課程自動彙整系統與查詢 GUI」（動機見 `proposal.md`）。經過對使用者提供之清單進行實測連線與結構探查，確認以下關鍵事實與限制：
1. **使用者與部署定位**：網站（GUI）供同事與學生共同瀏覽查詢，因此採用 **GitHub Pages 靜態網站 + GitHub Actions 定時爬蟲**，達成零伺服器成本、免自行開機維護。
2. **零 API 費用約束**：不依賴付費 LLM API Key，全部以 **Python HTML DOM 解析 + 台灣公文／簡章正規表示式（Regex）規則庫** 抽取 12 個欄位。
3. **官方積分白名單來源**：實測發現台灣臨床心理學會公開頁面 `https://taclip.org.tw/checked-list/`（Ninja Tables 表格）直接列出全台審核通過臨床心理師繼續教育積分之課程（含 `認證字號`、`課程性質`、`開始日期`、`開課單位`、`課程名稱`），可作為「是否有臨床心理師積分 = 是」之權威白名單，再與各學會公告內頁交叉比對補齊時間、費用、地點與報名網址。
4. **A 類網址實況修正**：原清單中 6 個不存在或誤植之網域已確認替換為真實官網（如 `tpsa.org.tw` 實為警安聯防協會，臺灣精神分析學會真實網址為 `https://psychoanalysis.org.tw/`；性諮商學會為 `https://tasctaiwan.tw/`；表創性藝術治療學會為 `https://ecata.org.tw/`；華人伴侶與家族治療協會為 `http://www.acft.org.tw/` 與亞太 EFT `https://asia-eft.com/`）。

## Goals / Non-Goals

**Goals:**
- 建立模組化的 Python 爬蟲架構，支援 15 組 A 類官網與 `taclip` 審核通過課程總表之抓取、錯誤隔離與禮貌性請求限制（Rate limiting / Timeout / Retry）。
- 實作高準確度的台灣公文／課程簡章純規則抽取器（日期轉民國年、時間區間、費用、地點／線上方式、報名期間、報名網址、臨床心理師積分三層判定與原文依據段落擷取）。
- 實作跨站去重與欄位互補合併（將 `taclip` 積分白名單與各學會詳細公告合併）。
- 產出靜態 `docs/data/courses.json` 與 `docs/data/courses.csv`（UTF-8 with BOM），並建立免建置步驟（Vanilla HTML/CSS/JS）的 GitHub Pages 響應式查詢 GUI 與 `=IMPORTDATA()` Google Sheets 一鍵同步功能。

**Non-Goals:**
- 第一版不實作需登入或違反服務條款之 Facebook 社團／粉專自動爬蟲（但可在 GUI 或資料層預留手動匯入結構）。
- 第一版不納入無固定網址之 C 類泛稱單位（如全台 22 縣市衛生局、各醫院官網逐一爬取）與 B 類綜合售票平台（Accupass、KKTIX、BeClass 全站搜尋），但保留透過 `taclip` 白名單及 `atcp` 轉知活動訊息間接涵蓋醫院與衛生局課程的能力。
- 不使用需要長期付費維護的雲端資料庫或後端伺服器。

## Decisions

### 1. 系統整體資料流與目錄結構

採用「Repo 即資料庫與靜態站台」架構，直接將爬蟲產出寫入 `docs/data/` 並由 GitHub Pages 託管 `docs/`：

```
+-------------------------------------------------------------------+
| .github/workflows/update-courses.yml (每日排程 + workflow_dispatch) |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
| scraper/ (Python 3.11+, httpx, beautifulsoup4, lxml)              |
|  +-- sources/       各學會列表與內頁抓取器 (BaseScraper 子類別)     |
|  +-- taclip_whitelist.py  抓取 taclip.org.tw/checked-list/ 積分表  |
|  +-- extractor.py   台灣公文/簡章 12 欄位 Regex + DOM 規則抽取器   |
|  +-- deduplicator.py 課程名稱正規化 + 民國日期比對與欄位互補合併    |
|  +-- exporter.py    輸出 docs/data/courses.json & courses.csv     |
+-------------------------------------------------------------------+
                                  |
                  +---------------+---------------+
                  |                               |
                  v                               v
+-----------------------------------+   +---------------------------+
| docs/index.html + app.js + style  |   | docs/data/courses.csv     |
| (GitHub Pages 查詢與篩選 GUI)      |   | - UTF-8 BOM 供 Excel 下載 |
| - 篩選：臨床積分(是/未知/否)       |   | - 供 Google Sheets 以     |
| - 篩選：線上/實體、免費、月份、來源 |   |   =IMPORTDATA() 自動同步  |
+-----------------------------------+   +---------------------------+
```

- **理由**：免除後端伺服器、CORS 問題與付費主機；同事與學生打開 GitHub Pages 網址即可瀏覽，且 Google Sheets 可直接透過公開 CSV 網址同步。

### 2. 純規則 12 欄位抽取器（`scraper/extractor.py`）設計

針對台灣公學會公告常見的半結構化格式（如 `一、活動名稱：...`、`◎課程資訊◎ 1.時間：...`、`【時間】...`、`★繼續教育積分：...`），採分欄規則抽取：

1. **課程日期（正規化為民國年 `YYY/MM/DD`）**：
   - 支援匹配 `(\d{3})\s*年\s*(\d{1,2})\s*月\s*(\d{1,2})\s*日`、`(\d{4})[/-](\d{1,2})[/-](\d{1,2})`、`(\d{3})[./-](\d{1,2})[./-](\d{1,2})`。
   - 若為西元年 $Y \ge 1912$，自動轉換為 $Y - 1911$，並統一補零為 `115/07/29` 格式；若為跨日課程則格式化為 `115/09/12–115/09/13`。
2. **上課時間**：
   - 匹配 `([0-2]?\d:[0-5]\d)\s*[~～\-–—至到]\s*([0-2]?\d:[0-5]\d)`。
3. **費用**：
   - 先搜尋帶有標籤之段落：`(?:費用|報名費|收費標準|課程費用)[：:\s]*([^\n。]+)`；若含 `免費`、`免收報名費`、`0元` 則正規化或保留簡短描述（如 `免費`、`$800`）。
4. **上課地點／方式**：
   - 先匹配 `(?:地點|辦理地點|上課地點|辦理方式|上課方式)[：:\s]*([^\n]+)`；若內文或標題含 `線上`、`視訊`、`Zoom`、`Google Meet`、`Webex` 且無實體地址則標記為 `線上`（或 `實體、線上混合`）。
5. **報名連結**：
   - 優先擷取內文中位於 `報名網址`、`報名連結`、`報名方式` 附近的超連結，或常見報名表單網域（`forms.gle`、`docs.google.com/forms`、`beclass.com`、`accupass.com`、`kktix.com`）；若無外部連結則使用該公告內頁網址本身。
6. **報名期間**：
   - 匹配 `(?:報名期間|報名日期|報名時間|即日起至)[：:\s]*([^\n。]+)`，或列表頁上標註之開放報名區間。
7. **臨床心理師積分三層判斷規則**：
   - **第一層（白名單命中）**：比對 `taclip.org.tw/checked-list/`，若課程名稱（去除標點與空白後包含或高度重合）且日期相符 → `是否有臨床心理師積分 = "是"`，`積分判斷依據段落 = "台灣臨床心理學會審核通過（認證字號：TACP...，性質：...）"`。
   - **第二層（內文關鍵字正向／負向判定）**：以句號、換行切分內文，找出所有包含 `(積分|學分|繼續教育)` 的句子：
     - 若句子明確含 `不申請`、`無申請`、`恕不提供` → `"否"`（附原句）。
     - 若句子含 `臨床心理師`（或同時列舉 `臨床、諮商心理師`）→ `"是"`（附原句）。
     - 若句子僅含 `諮商心理師`、`社工師`、`精神科專科醫師` 而未含 `臨床` → `"否"`（附原句）。
     - 若句子僅泛稱 `心理師繼續教育積分`、`醫事人員積分` 未指明臨床或諮商 → `"未知"`（附原句）。
   - **第三層（來源預設與未知回退）**：若內文完全未提到積分字眼，則設為 `"未知"`，依據段落填寫 `"課程公告內文未提及繼續教育積分資訊"`。

### 3. 跨來源去重與合併策略（`scraper/deduplicator.py`）

- 以 `(正規化課程名稱關鍵字, 課程開始日期)` 作為去重鍵。
- 當 `taclip` 審核通過表（僅有 5 欄：認證字號、課程性質、開始日期、開課單位、課程名稱）與 `atcp` 或其他學會公告撞名且同日時，將兩筆紀錄合併：以學會公告的詳細 `上課時間`、`費用`、`上課地點／方式`、`報名連結`、`報名期間` 補齊 `taclip` 紀錄，並同時保留 `taclip` 的官方認證字號作為最高可信度的積分依據。

## Risks / Trade-offs

- **[Risk] 部分學會網站將簡章放在 PDF 或圖片海報中（例如 `tap.org.tw` 或部分轉知公告僅附海報）** → **Mitigation**：規則抽取器先從 HTML 內文與標題抽取可取得的欄位（名稱、主辦單位、日期、公告網址），缺漏之細節欄位（如時間、費用）留空並在 GUI 上提供直接點擊原公告／簡章連結，不強行猜測。
- **[Risk] 外部學會網站改版、維護（如 `tsos.org.tw` 503）或憑證異常（如 `tpos` HTTP、`tpsa` 舊網址誤植）** → **Mitigation**：每個來源獨立 try/except 並設定連線 timeout（15 秒）；若單一站點失敗，保留上次成功抓取的課程資料或僅跳過該站點，並在網站頁尾／執行日誌顯示各來源最後成功同步狀態。
- **[Risk] `taclip.org.tw/checked-list/` 僅有「開始日期」與「課程名稱」，ไม่มี報名連結** → **Mitigation**：若某筆 `taclip` 審核通過課程未能在其他 14 個學會網站找到對應公告，其 `報名連結` 預設指向以「開課單位 + 課程名稱」構成的 Google 搜尋連結或 `taclip` 審核表頁面，讓同事與學生仍可一鍵查找報名頁。
